Условие задачи для лабораторной работы (Вариант: Логистическая цепочка поставок)
Описание предметной области:
Разработать графовую базу данных для моделирования логистической цепочки поставок продовольственных товаров.
Система должна связывать между собой:
 - производственные предприятия (заводы),
 - крупные распределительные центры (дистрибьюторы)
 - конечные розничные торговые точки (магазины),
обеспечивая движение грузов, транзитные маршруты и структуру владения фирменными сетями.

Требования:
В базе данных должны быть созданы и заполнены данными (не менее 10 строк в каждой таблице сущностей) следующие компоненты:
Таблицы узлов:
 - Factory (название, город, специализация)
 - Distributor (название, регион, общая вместимость)
 - Store (название, адрес, тип торговой точки)

Таблицы рёбер :
 - Supplies (Связывает направления: Завод-Дистрибьютор и Дистрибьютор-Магазин. Содержит свойство: Объем поставки в тоннах).
 - Transfers (Связывает направления: Дистрибьютор-Дистрибьютор для перемещения товаров между ними. Содержит свойство: Расстояние в километрах).
- Owns_Franchise (Связывает направление: Завод-Магазин в случаях, когда магазин является фирменной торговой точкой бренда. Содержит свойство: Доля владения в процентах).

Используя специализированные возможности графовых баз данных в MS SQL Server, разработать и выполнить запросы:
 - Какие магазины получают товары через логистический узел «Минск-Хаб Центральный»?
 - Какие фирменные магазины напрямую принадлежат заводам на правах франшизы или полной собственности?
 - Найти полную логистическую цепочку (Завод-Дистрибьютор-Магазин)

Выполнить поиск кратчайших путей (SHORTEST_PATH) между удаленными распределительными центрами для расчёта суммарного километража доставки.
При выполнении задания использовать операторы языка T-SQL для создания графовых таблиц (AS NODE, AS EDGE), их наполнения, а также специфические графовые конструкции, такие как MATCH, SHORTEST_PATH, FOR PATH, STRING_AGG и сопутствующие фильтры в секции WHERE.
